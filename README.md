# Kavach
Privacy-first image misuse support tool.
Built for recHERsion 2026 (PS2: Women's Safety).
Team: Kavach

## Setup
1. Clone repo
2. python -m venv venv
3. venv\Scripts\activate
4. pip install -r requirements.txt
5. python app.py

## New Features (Backend-work)
- Integrity check (integrity.py) - SHA256 hash verification
- Resource helper (resources.py)
- Robustness test (robustness_test.py)
- Unit tests in tests/ - 13 tests passing
